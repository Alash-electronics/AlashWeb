# Changelog

## 1.0.0
- Первый выпуск: веб-панель для ESP32 и ESP8266 на встроенном WebServer.
- Элементы: кнопка, переключатель, ползунок, значение с графиком за минуту, строка текста; страница строится из описания, обновляется раз в секунду, тёмная тема, подписи по-русски.
- Пароль (HTTP Basic), проверка идентификаторов, ограничение значения ползунка на стороне платы.
- Понятные ошибки и `diagnose()` на русском, казахском и английском.
